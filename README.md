# GlassDroid (alpha)

Android 13-friendly iOS-inspired launcher starter for Samsung Galaxy A03 Core.

Features in the **current alpha**: launcher (home screen), app grid, Control Center **page** linking to Android controls, lock-screen visual preview (not system lock replacement), and permission settings. It does not override Android's secure lock screen or system Quick Settings shade. This build does not replicate all iOS 26 visuals.

## APK via GitHub Actions
Go to **Actions > Build GlassDroid APK**, open the latest successful run, and download the **GlassDroid-debug-apk** artifact (ZIP). Unzip to obtain `app-debug.apk`. It is a debug build intended for testing, not Play Store release.

To restore original Samsung launcher, visit Android Settings > Apps > Default apps > Home app and choose the original home app. Grant only permissions you actually want to use.
